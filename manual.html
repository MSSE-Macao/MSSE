📘 MSSE 網站管理圖解手冊

🧭 一、網站結構

網站主要由以下部分組成：

  • index.html（首頁）
  • js/events.js（所有活動資料）
  • data/home.json（首頁精選活動）
  • images/events（活動圖片）
  • docs（PDF文件）

🟢 二、如何新增活動（最重要）

Step 1：上傳圖片

放入：

images/events/event3.jpg

Step 2：修改 events.js

{ id: "event3", title: "新活動名稱", date: "2026-08-01", desc: "活動內容", image: "images/events/event3.jpg", link: "https://報名連結", status: "upcoming" }
✔ status: upcoming（未來） / past（過往）

🟡 三、首頁精選活動

修改：

data/home.json
{ "title": "新活動", "image": "images/events/event3.jpg", "link": "event-detail.html?id=event3" }

🟣 四、更新會訊 PDF

1️⃣ 放入 docs 資料夾

2️⃣ 修改 newsletter.html

🔵 五、GitHub 更新方法

  1. 進入 GitHub
  2. 打開檔案
  3. 按 ✏️ Edit
  4. 修改內容
  5. 按 Commit changes

👉 約10–30秒後網站會自動更新

⚠️ 六、常見錯誤

  • 圖片名稱大小寫錯誤 ❌
  • JSON 漏逗號 ❌
  • 圖片路徑錯誤 ❌

🎯 七、日常管理流程

  1. 上傳圖片
  2. 修改 events.js
  3. 修改 home.json（如需要）
  4. Commit
